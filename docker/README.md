# Cosint — النسخة الكاملة (Docker)

ثماني وحدات استخبارات مفتوحة المصدر. تُدخل بريداً أو اسم مستخدم أو رقم هاتف أو
نطاقاً، فتعمل كل وحدة مطابقة بالتوازي، وتتمحور تلقائياً على المعرّفات المكتشفة،
ثم تدمج كل شيء في تقرير واحد ورسم علاقات واحد.

للنسخة الخفيفة بلا خادم، انظر [`../vercel`](../vercel).

---

## التشغيل

```bash
cp .env.example .env
docker compose up -d --build
# http://localhost:8000
```

البناء يستغرق عدة دقائق أول مرة — يثبّت holehe و maigret و ghunt و sherlock.

### بدون Docker

```bash
pip install -r requirements.txt
pipx install holehe && pipx install maigret && pipx install ghunt
uvicorn app.main:app --port 8000
```

`pipx` مقصود: هذه الأدوات تثبّت إصدارات متضاربة من `aiohttp` و `httpx`، وعزل كل
واحدة في بيئتها هو الحل الوحيد الموثوق لتشغيلها معاً. الـ Dockerfile يفعل نفس
الشيء عبر venvs منفصلة تحت `/opt/venvs`.

## الوحدات

| الوحدة | المدخل | ماذا تفعل | تحتاج إعداداً |
|---|---|---|---|
| `email_profile` | بريد | صيغة، MX، تصنيف النطاق، اشتقاق اسم المستخدم | — |
| `gravatar` | بريد | صورة، اسم معروض، حسابات معلنة | — |
| `holehe` | بريد | ~120 موقعاً: هل البريد مسجّل فيها | holehe |
| `breaches` | بريد | XposedOrNot + LeakCheck مجاناً، HIBP اختياري | — |
| `ghunt` | بريد | معرّف Gaia، الصورة، مراجعات الخرائط، التقويم | `ghunt login` |
| `maigret` | اسم مستخدم | آلاف المنصّات (sherlock كبديل) | maigret |
| `phone_profile` | هاتف | الدولة، المشغّل، نوع الخط، المناطق الزمنية | — |
| `domain_infra` | نطاق | A/NS/TXT، SPF، DMARC | — |

أي وحدة غير مثبّتة تُبلّغ `not_configured` ولا تُسقط الفحص.

### التمحور

البريد يشتق نطاقه واسم مستخدم محتمل، فتعمل عليهما وحداتهما في موجة ثانية.
يُضبط بـ `MAX_PIVOTS` (افتراضي 3). أي معرّف مشتق يرث ثقة منخفضة، وكل ما يُبنى
عليه يرثها بدوره.

## الإعداد

كل المفاتيح اختيارية. انظر `.env.example`.

| المتغيّر | الوظيفة |
|---|---|
| `HIBP_API_KEY` | يفعّل Have I Been Pwned (مدفوع، ~$4/شهر) |
| `NUMVERIFY_KEY` | إثراء بيانات الهاتف. `phonenumbers` يعمل بلا اتصال بدونه |
| `MODULE_TIMEOUT` | سقف زمن الوحدة الواحدة، افتراضي 180ث |
| `MAX_CONCURRENT_MODULES` | التوازي، افتراضي 6 |
| `MAX_PIVOTS` | حد المعرّفات المتتبَّعة، افتراضي 3 |
| `DISABLED_MODULES` | أسماء مفصولة بفاصلة، مثل `holehe,ghunt` |

### GHunt

يحتاج جلسة Google مرة واحدة:

```bash
docker compose exec osint /opt/venvs/ghunt/bin/ghunt login
```

الجلسة تُحفظ في وحدة تخزين `ghunt-creds` فتبقى بعد إعادة التشغيل.

## المخرجات

- **الواجهة** على `/` — نتائج مصنّفة، رسم علاقات تفاعلي، سجل تنفيذ حيّ
- **تقرير للطباعة** على `/api/scan/{id}/report.html` — مستقل، يعمل بلا اتصال
- **JSON** على `/api/scan/{id}/report.json` — كامل بما فيه المخرجات الخام
- **API** موثّق على `/api/docs`

## البنية

```
app/main.py              مسارات FastAPI، مهام خلفية
app/orchestrator.py      تشغيل الوحدات، دمج النتائج، التمحور
app/schemas.py           Entity / Edge / Finding — العقد المشترك بين الوحدات
app/graph.py             بناء الرسم لـ Cytoscape
app/report.py            تصيير تقرير الطباعة
app/db.py                سجل المهام في SQLite
app/modules/             الوحدات الثماني
```

الوحدة الجديدة ترث `Module`، تعلن `accepts`، وتُسجَّل بـ `@register`. المنسّق
يلتقطها تلقائياً ويعرف متى يشغّلها.

## ملاحظات

- `docker-compose.yml` يربط المنفذ بـ `127.0.0.1` عمداً. لا تعرضه للإنترنت.
- HIBP يحتاج مفتاحاً مدفوعاً. البدائل المجانية مدمجة لكن تغطيتها أقل.
- `holehe` يعمل عبر تدفّقات «نسيت كلمة المرور» على مواقع طرف ثالث — يخالف شروط
  استخدام كثير منها وقد يصطدم بحدود المعدّل.
- فحص شخص بلا تفويض قد يخالف GDPR وقوانين محلية.
