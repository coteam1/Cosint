# Cosint

أداة استخبارات مفتوحة المصدر، ذاتية الاستضافة. تُدخل معرّفاً واحداً — بريد،
رقم هاتف، اسم مستخدم، أو نطاق — فتُشغّل كل وحدة متاحة عليه بالتوازي، تدمج
المخرجات في رسم علاقات واحد، وتعطي كل نتيجة درجة ثقة.

نسختان في هذا المستودع. اختر واحدة.

---

## أيّهما تختار

| | [`docker/`](./docker) | [`vercel/`](./vercel) |
|---|---|---|
| الوحدات | 8 | 5 |
| بريد · هاتف · نطاق · تسريبات | ✅ | ✅ |
| اسم مستخدم (holehe · maigret) | ✅ | ❌ |
| حسابات Google (GHunt) | ✅ | ❌ |
| يحتاج خادماً | نعم | لا |
| زمن الفحص | دقائق | ثوانٍ |
| التخزين | SQLite + سجل مهام | بلا حالة |

**خذ `docker/`** إن أردت كل شيء ولديك خادم أو جهاز تشغّل عليه.
**خذ `vercel/`** إن أردت رابطاً يعمل خلال دقيقتين بلا بنية تحتية.

الواجهة والتصميم ونموذج درجات الثقة مشتركة بين الاثنتين.

## تشغيل سريع

```bash
# النسخة الكاملة
cd docker && cp .env.example .env && docker compose up -d --build
# http://localhost:8000

# نسخة Vercel
cd vercel && npx vercel --prod
```

تفاصيل كل نسخة في README الخاص بمجلّدها.

## نموذج درجات الثقة

هذا ما يميّز الأداة عن تجميع مخرجات أدوات متفرّقة. كل نتيجة تحمل نسبة:

| النسبة | المعنى |
|---|---|
| 100% | المصدر أعاد المعرّف صراحةً |
| 80% | شبه مؤكَّد — مثل ملف Gravatar مرتبط ببصمة البريد |
| 50% | مُشتق — اسم المستخدم المأخوذ من `john.doe@gmail.com` تخمين لا حقيقة |
| 30% | محتمل فقط |

المشتقّات تظهر بالأزرق في الرسم البياني. الكيان الذي يؤكّده مصدران مستقلان
يُحسب في عدّاد «مؤكَّد من مصدرين+»؛ مصدر الإدخال نفسه لا يُحتسب تأكيداً لذاته.

تطابق اسم مستخدم على منصّة ما ليس إثباتاً أنه نفس الشخص. الأداة تميّز بين ما
تأكّد وما اشتُقّ، وتعرض الفرق بوضوح بدل دمجهما في قائمة واحدة.

## استخدام مسؤول

- فحص شخص بلا تفويض قد يخالف GDPR وقوانين محلية. خانة تأكيد التفويض في الواجهة
  احتكاك مقصود، وليست غطاءً قانونياً.
- `holehe` يعمل عبر استغلال تدفّقات «نسيت كلمة المرور» على مواقع طرف ثالث. هذا
  يخالف شروط استخدام كثير منها وقد يصطدم بحدود المعدّل. عطّله عبر
  `DISABLED_MODULES` إن لم يناسبك.
- لا تنشر أياً من النسختين كخدمة عامة. `docker-compose.yml` مربوط بـ `127.0.0.1`
  عمداً، وواجهة Vercel تحمل `noindex`.
- درجة الثقة تقدير آلي. تحقّق يدوياً قبل أي قرار يمسّ إنساناً.
