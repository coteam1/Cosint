# OSINT Suite Lite — Vercel edition

خمس وحدات استخبارات مفتوحة المصدر تعمل على دوال Vercel بلا خادم. أدخل بريداً
أو رقم هاتف أو نطاقاً، واحصل على تقرير واحد مرتّب مع رسم علاقات ودرجة ثقة لكل نتيجة.

هذه نسخة مخفّفة من مشروع Docker الكامل. اقرأ قسم **ما ليس هنا** قبل النشر.

---

## النشر

```bash
npm i -g vercel
vercel                 # معاينة
vercel --prod          # إنتاج
```

أو ادفع المستودع إلى GitHub واربطه من لوحة Vercel. لا يحتاج أي إعداد إضافي —
`vercel.json` يضبط التوجيه والمهلة.

### تشغيل محلي

```bash
pip install -r requirements.txt uvicorn
python dev.py          # http://127.0.0.1:8000
```

`dev.py` موجود لأن Vercel يخدم `public/` من الحافة ويشغّل `api/index.py` كدالة —
لا شيء يربط الاثنين محلياً، فهذا الملف يفعل ذلك. Vercel لا يستورده أبداً.

### متغيّرات البيئة (كلها اختيارية)

| المتغيّر | الوظيفة |
|---|---|
| `HIBP_API_KEY` | يفعّل Have I Been Pwned. بدونه تعمل XposedOrNot و LeakCheck مجاناً |
| `HTTP_TIMEOUT` | مهلة كل طلب صادر، افتراضي 8 ثوانٍ |
| `SCAN_BUDGET` | سقف الفحص الكلي، افتراضي 45ث. أبقِه أقل من `maxDuration` |

اضبطها في Vercel تحت **Settings → Environment Variables**.

## الوحدات الخمس

| الوحدة | المدخل | ماذا تفعل |
|---|---|---|
| `email_profile` | بريد | صيغة، سجلات MX، تصنيف النطاق، اشتقاق اسم المستخدم |
| `gravatar` | بريد | صورة رمزية، اسم معروض، حسابات معلنة، موقع |
| `breaches` | بريد | XposedOrNot + LeakCheck مجاناً، HIBP إن توفّر مفتاح |
| `domain_infra` | نطاق | سجلات A/NS/TXT، SPF، DMARC، خدمات مُتحقَّقة |
| `phone_profile` | هاتف | الدولة، المشغّل، نوع الخط، المناطق الزمنية — بلا اتصال |

البريد يتمحور تلقائياً إلى نطاقه فتعمل `domain_infra` عليه في نفس الطلب.

## ما ليس هنا

| الوحدة | لماذا سقطت |
|---|---|
| `holehe` | يحتاج عملية فرعية و30–120 ثانية |
| `maigret` | عملية فرعية، ويجرّ pandas و lxml فيتجاوز حدّ 250MB للحزمة |
| `ghunt` | يحتاج جلسة Google مخزّنة على قرص دائم |

**النتيجة العملية:** لا بحث باسم المستخدم، ولا حسابات Google. إدخال اسم مستخدم
يُرجع 422 برسالة واضحة بدل الفشل الصامت. إن احتجت هذين المحورين، شغّل نسخة Docker.

### قرارات تقنية

**ملف واحد.** `api/index.py` يحتوي كل شيء. Vercel يحزم الدالة بتحليل ساكن لنقطة
الدخول، والملف الواحد يزيل أي سؤال عمّا يُضمَّن وما لا يُضمَّن.

**DNS عبر HTTPS بدل dnspython.** حزم UDP على المنفذ 53 من Lambda غير موثوقة.
DoH يعمل عبر HTTPS دائماً، ويسقط اعتمادية من الحزمة. Cloudflare أساسي مع تحويل
تلقائي إلى Google عند الفشل.

**بلا قاعدة بيانات وبلا polling.** كل الوحدات المتبقية تنتهي في ثوانٍ، فالفحص
طلب واحد يرجع التقرير كاملاً. السجل يُحفظ في `localStorage` عند المتصفح.

**Cytoscape مُضمَّن محلياً** في `public/vendor/` — الرسم يعمل بلا CDN.

## درجات الثقة

كل نتيجة تحمل نسبة. الفرق ليس تجميلياً:

- **100%** — المصدر أعاد المعرّف صراحةً
- **80%** — شبه مؤكَّد، مثل ملف Gravatar مرتبط ببصمة البريد
- **50%** — مُشتق. اسم المستخدم المأخوذ من `john.doe@gmail.com` تخمين لا حقيقة
- **30%** — محتمل فقط

المشتقّات تظهر بالأزرق في الرسم البياني. الكيان الذي يؤكّده مصدران مستقلان
يُحسب في عدّاد «مؤكَّد من مصدرين+» — مصدر الإدخال نفسه لا يُحتسب تأكيداً.

## قبل أن تستخدمها

- ثبّت المشروع على **noindex** (موجود في `index.html`) ولا تنشره كأداة عامة.
- Vercel يستخدم IPs مشتركة. الاستعلامات هنا خفيفة، لكن لا تحوّلها إلى ماسح جماعي —
  ذلك يخالف سياسة الاستخدام المقبول ويُعرّض المشروع للإيقاف.
- فحص شخص بلا تفويض قد يخالف GDPR وقوانين محلية. خانة تأكيد التفويض في الواجهة
  احتكاك مقصود، وليست غطاءً قانونياً.
- درجة الثقة تقدير آلي. تحقّق يدوياً قبل أي قرار يمسّ إنساناً.
